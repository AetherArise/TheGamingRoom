# TheGamingRoom

The Gaming Room is a local game development company looking for help managing their server architecture while producing a desktop version of their game, "Draw it or Lose it". They needed help developing software for their game that could manage interacting with multiple types of devices in one play session, and storing that data for future user use.

During my creation of the documentation used for the project, I felt I was very successful in outlining the differences in OS requirements, their specific uses, and how different devices could impact project development in different ways.

Having an outlined design document was essential in properly producing the code within the parameters needed for the project. By having a specific outline along with data I was better able to focus the software to specific needs of the company. For example specific security and web-based requirements outlined in the documentation.

One part of my work that I would revise if able to would be the requirements section. I feel as though I could of gotten more information about the specific security needs for the application, and outlined what I needed to add relating to security features.

During the creation of the documentation I took multiple user needs into consideration. For example, since the application already exists on mobile devices it was essential to make sure the desktop version was fully compatible with the mobile application. As I stated earlier later on in the production of the application I did focus largely on security requirements (though it is not fully stated early in the documentation), but it was important to keep security in the forefront of my mind due to the vastness of this application. Since it could be played on multiple OS and used by hundreds of players with hundreds of accounts, it was imperative to make sure that account information was securely hashed and web-data was securely autherized!

My approach to developing this software was to keep the overall goal of the application in mind. I knew what my client had envisioned for this piece. A vastly accessible game that could be enjoyed on specific user accounts with secure data protection. Keeping these factors in mind I was able to weave an application that our client hoped for! In the future I would keep in mind the main concerns of the customer in the forefront of my mind at all times. If an issue is important to the customer, that means its 10x more important to keep in mind while in development.
